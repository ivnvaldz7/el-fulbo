# Propuesta: formato de equipo y posiciones desde Card Global

La creación de un Equipo debe pedir únicamente el formato de fútbol del equipo. La posición del creador no pertenece a este paso: se toma de su Card Global, que es la fuente de verdad del jugador.

El formato se persiste en `teams.modality` y admite F5, F6, F7, F8, F9 y F11.
